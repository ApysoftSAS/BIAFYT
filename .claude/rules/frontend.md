# Frontend Rules

- Use React 19 and the existing project architecture.
- Prefer existing components and utilities before creating new abstractions.
- Keep components focused and avoid unnecessary prop drilling.
- Use the existing AppContext for global state.
- Do not introduce a state-management library without explicit approval.
- Do not introduce a router unless explicitly approved.
- Follow the existing CSS architecture and design tokens.
- Never hardcode application colors; use the existing theme variables.
- Keep UI text and comments in Spanish when editing existing code.
- Consider mobile-first behavior and touch interaction.
- Avoid unnecessary dependencies.
- Preserve existing behavior unless the requested change requires otherwise.
