# UX/UI Rules

- Design mobile-first.
- Prioritize clarity, hierarchy and ease of use over decoration.
- Preserve BIAFYT's existing visual identity unless a redesign is explicitly requested.
- Reuse existing components, spacing, typography and color tokens.
- Do not introduce new visual patterns when an existing pattern can be reused.
- Consider touch targets, loading states, empty states, errors and feedback.
- Maintain sufficient contrast for functional text.
- Preserve visible focus states for keyboard and accessibility users.
- Respect prefers-reduced-motion where animations are introduced or modified.
- Avoid unnecessary animations and visual effects.
- Evaluate important UI changes from the user's actual task flow, not only visual appearance.
