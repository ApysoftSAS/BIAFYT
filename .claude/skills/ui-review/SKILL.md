# UI/UX Review

Evaluate the interface as a polished, modern mobile fitness product.

## Evaluate

Consider:

- Visual hierarchy.
- Information density.
- Typography.
- Spacing.
- Color and contrast.
- Component consistency.
- Touch targets.
- Navigation.
- User flow.
- Feedback and interaction states.
- Loading states.
- Empty states.
- Error states.
- Accessibility.
- Responsive behavior.
- Animation and motion.
- Mobile usability.

## Design principles

- Prioritize clarity over decoration.
- Preserve BIAFYT's existing visual identity unless a redesign is explicitly requested.
- Reuse existing components, tokens and patterns.
- Avoid unnecessary visual complexity.
- Design mobile-first.
- Maintain sufficient contrast for functional information.
- Consider keyboard, screen-reader and touch accessibility.
- Respect reduced-motion preferences when relevant.
- Make important actions visually obvious.
- Avoid introducing visual patterns that conflict with the existing design system.

## Product thinking

For important screens, evaluate:

- What is the user's primary goal?
- Is the next action obvious?
- Is unnecessary information competing for attention?
- Does the interface provide adequate feedback?
- Does the flow feel like a real product rather than a prototype?

## Output

When reviewing a screen or flow, report:

1. Current UX.
2. Strong points.
3. Problems.
4. Severity.
5. Recommended changes.
6. Expected user benefit.

Do not modify files unless explicitly requested.
